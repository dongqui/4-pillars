# 관계 지도 라이트 리디자인 — 사이드 패널·새 팔레트·모달 추가 폼

2026-08-30 · 상태: 설계 확정 대기
시안: Claude Design `사주` 프로젝트의 `Saju Relationship Map.dc.html` (projectId 42e876d6-1a2a-488e-93aa-825a838687ce). 시안 내 3D 영역은 "placeholder: 색/느낌만" — 색만 참고하고 구조는 따르지 않는다(사용자 확인).

## 목표

1. 지도 화면을 다크 → **라이트 테마**로 전환한다 (페이지·헤더·패널·모달·3D 배경).
2. PersonSheet 를 없애고, **구역별 그룹 목록**의 사람 행에 궁합 단락(relationNote)을 인라인으로 싣는다 (사용자 확인: "목록 인라인, 시트 삭제").
3. 5구역 색을 시안 팔레트로 교체하고, 라이트 배경에서의 가독성 체계를 다시 세운다.
4. 추가 폼을 시트에서 **모달**로 바꾸고 입력 UX(년/월/일 분리·자동 이동·검증)를 시안대로 만든다.

## 확정된 판단 (사용자 승인)

- 연결선은 시안의 중립 회색이 아니라 **role 색 원칙 유지** (회색 선은 placeholder 판정).
- 공유하기 버튼은 **모두에게 표시** (현재는 소유자만; 링크는 현재 URL이라 숨길 실익 없음).
- hue 간격 테스트 하한 40° → **38°** (시안 hex 유지가 우선; 초록 h160·하늘 h199는 명도 차로도 갈린다).
- 그래픽 색과 텍스트 색을 분리한다 (아래 §1).

## 디자인 토큰 (시안에서 추출)

- 배경: 지도 `#F8FAFC` + 중앙 하단 블루 글로우 `rgba(37,99,235,.09)` (radial) · 페이지/패널 `#fff`
- 프라이머리: `#2563EB` (hover `#1D4ED8`) — 나 오브, CTA 버튼
- 텍스트: 본문 `#0F172A` · 보조 `#475569`/`#334155` · 약함 `#94A3B8` · 플레이스홀더 `#B6BDC7`
- 보더: `#E5E7EB` (컨트롤) · `#F1F5F9` (구분선) · 입력 `#E2E8F0`
- 에러: `#F43F5E`
- 구역 5색 (그래픽): fill `#10B981` · beside `#F59E0B` · express `#8B5CF6` · move `#DB2760` · refine `#0EA5E9`
- 폰트·라운드·그림자는 기존 앱 컨벤션(Tailwind)을 따르되 시안의 크기 감각(칩 10px 라운드, 모달 22px, 입력 13px)을 옮긴다.

## 설계

### 1. 색 시스템 — `_data/role-colors.ts`

- `ROLE_HUE` 를 시안 5색의 HSL 로 교체 (hex → HSL 변환값을 주석에 원 hex 와 함께 기록):
  - fill `#10B981` ≈ h160 · beside `#F59E0B` ≈ h38 · express `#8B5CF6` ≈ h258 · move `#DB2760` ≈ h337 · refine `#0EA5E9` ≈ h199
- `STATE_SHIFT`(六合/沖 변조)와 `roleHsl`/`nodeColor`/`roleColor` 시그니처는 유지.
- **`roleTextColor(role): string` 추가**: ROLE_HUE 의 hue·채도를 유지한 채 명도를 낮춰 `#F8FAFC` 대비 **4.5:1 이상**을 보장하는 텍스트용 색. 구현은 "명도를 1씩 내리며 4.5 를 처음 넘는 l" 같은 결정적 탐색이어도 되고 고정 l 테이블이어도 된다 — 테스트가 대비를 잠근다.
- 쓰임의 구분: **그래픽(3D 노드·연결선·목록 점·아바타 배경) = `roleColor`/`nodeColor`** (시안 hex 그대로), **색 텍스트(그룹명·별명 태그) = `roleTextColor`**.
- `role-colors.test.ts` 개정:
  - hue 간격 하한 40 → 38 (근거 주석).
  - 기존 "배경 #0f172a 대비 4.5" 삭제 → "**`roleTextColor` 가 `#F8FAFC` 대비 4.5 이상**" + "`roleTextColor` 는 hue 를 바꾸지 않는다"로 교체. 그래픽 색에는 대비 하한을 걸지 않는다(시안 확정 팔레트; 식별은 텍스트 변형이 담당).
  - 상태 변조 테스트(六合 밝아짐·沖 채도↑·hue 불변·15색 유효)는 유지.

### 2. 3D 월드 — 색만 교체, 구조 유지

건드리지 않는 것: `layout.ts`(배치) · `camera.ts`/`CameraRig` · 선 강조 상수(OPACITY 3종) · `node-visual.ts` 의 광량 불변식 · 선택/포커스 로직.

- `World.tsx`: `<color>`·`<fog>` `#0F172A` → `#F8FAFC` (fog 거리 값은 유지).
- `connections.ts`: 나 쪽 끝을 죽이는 연산을 **검정 곱(`× CONNECTION_SELF_DIM`) → 배경색으로 lerp** 로 교체. 라이트 배경에서 "중심이 탁해지지 않게 배경 쪽으로 물러난다"는 같은 의도의 라이트판이다. lerp 는 기존 원칙대로 **linear 공간에서** 하고, srgbToLinear 는 유지한다. 배경 상수(`#F8FAFC`)는 World 의 배경과 한 곳에서 공유한다(예: connections.ts 가 export, World 가 import — 두 값이 갈라지면 lerp 목적이 깨진다). 불투명도 상수 3종(0.14/0.55/0.07)은 우선 유지하되, 라이트 배경 실측으로 과하거나 약하면 검증 단계에서 조정.
- `connections.test.ts`: 검정 곱 검산 → 배경 lerp 검산으로 교체.
- `SelfCore.tsx`: 나 오브를 블루 계열로 — 코어 `#2563EB`, 하이라이트 `#7EB3FF` (시안의 radial 감각). 기존 지오메트리·글로우 구조 유지.
- `PersonMarker.tsx`(drei Html 명패): 라이트 칩으로 — 흰 배경 `#fff`, 보더 `#E5E7EB`, 이름 `#0F172A`, 별명 배지는 그 구역의 연한 배경 + `roleTextColor` 텍스트(시안의 알람 배지 감각: 연분홍 배경 + 진분홍 글자). dim/boost/selected 동작은 유지하고 색만 라이트로.
- `RegionLabels.tsx`: 라벨 텍스트 `roleTextColor`, 보조 텍스트는 슬레이트 계열 라이트 값.
- `node-visual.ts` 는 광량 규칙이므로 원칙적으로 무변경. 라이트 배경에서 글로우가 안 보이거나 과하면 검증 단계에서 강도만 조정(불변식 테스트는 유지).

### 3. 레이아웃 — MapShell 재구성

- 루트를 **flex 컬럼**(h-full)으로: 헤더(in-flow) / 본문(flex-1, min-h-0).
- 본문: **데스크톱(md↑) row = [지도 flex-1 | 패널 w-[400px] border-l]**, **모바일 column = [지도 flex-1 | 패널 하단, 펼침 시 max-h-[58vh]]**.
- 지도 영역: 3D 캔버스 + 우하단 **+나도 추가하기** 블루 필 버튼(영역 내 absolute).
- 판 상태 단순화: 시트가 사라지므로 배타 규칙은 "추가 모달 하나"만 남는다. `selectedId` 는 유지 — 3D 강조 + 목록 행 하이라이트용.
- **선택의 양방향**: 3D 노드 탭 → 행 하이라이트 + `scrollIntoView`(패널이 접혀 있으면 펼친다) · 행 탭 → 3D 선택(카메라 플라이). 빈 캔버스 탭 해제 동작 유지.
- `MapHeader`: 라이트(흰 배경 블러, 보더 `#F3F4F6`), 공유하기는 **항상 표시** — 아웃라인 필 스타일. 공유 로직(navigator.share → clipboard 폴백, 토스트)은 그대로.

### 4. PeopleList 개편 (라이트 사이드 패널)

- 헤더 행: "전체 N명" + 접기/펼치기 라벨 + 원형 캐럿(회전 애니메이션). 모바일에서는 상단 손잡이 바(시안의 36×4px). **기본 펼침** (데스크톱·모바일 공통, 시안 기본값).
- 그룹: `ROLE_ORDER` 순서, 헤더 = 8px 색 점(`roleColor`) + 구역명(`roleTextColor`) + 인원수. `ROLE_ICON` 이모지는 제거(시안에 없음 — 색 점이 그 역할).
- 사람 행:
  - 이니셜 아바타(34px 원): 배경은 그 구역 연한 톤(`roleColor` + 낮은 알파), 글자는 `roleTextColor`.
  - 1행: 이름(볼드) + 별명 태그(`DISPLAY_TITLES[role][feature]`, `roleTextColor`). **六合/沖 라벨(`FEATURE_LABELS`) 표기는 제거** — 별명 15개가 이미 소구역을 구분한다.
  - 2행: 장면명(`sceneName`, 약한 색).
  - 3행: **`relationNote(centerElement, role, feature)` 단락** (13px, `#94A3B8`보다 진한 보조색, `text-wrap:pretty`).
  - sameDayPillar 인 사람은 단락 아래 "일주가 통째로 같아요" 한 줄 유지 (시트에서 옮겨 온다).
  - 소유자에게 지우기 텍스트 버튼(hover 시 빨강).
- props 에 `centerElement: Element` 추가 (MapShell 이 이미 가진 값을 내린다).
- 선택 하이라이트: `selectedId` 행에 연한 배경.
- 접근성 패턴(행 div role="button" + 내부 지우기 버튼)은 기존 방식 유지.

### 5. PersonSheet 삭제

- `PersonSheet.tsx` 삭제, MapShell 의 시트 렌더·관련 상태 제거. `relationNote` 호출부는 PeopleList 로 이동. lastShown(닫힘 애니메이션) 패턴은 시트와 함께 사라진다.

### 6. AddPersonSheet → AddPersonModal

- 오버레이(`rgba(15,23,42,.44)` + blur) 클릭으로 닫힘. 데스크톱: 중앙 max-w 420px, 라운드 22px. 모바일: 하단 시트(라운드 22px 22px 0 0).
- 내용: 오버라인 "관계 지도" / 제목 "지도에 추가하기" / "이름과 생년월일만 있으면 돼요."
- 이름 입력(placeholder "예: 백상현").
- 생년월일: 양력/음력 세그먼트 토글 + **년(4)·월(2)·일(2) 분리 박스**. 숫자만 허용, 년 4자리·월 2자리 입력 시 다음 칸 자동 포커스. 포커스 링(파랑), 에러 시 보더 `#F43F5E`.
- 힌트 줄: 기본 "시간은 몰라도 괜찮아요." / 검증 실패 시 "날짜를 다시 확인해 주세요" (연도 1900~현재년, 월 1~12, 일은 해당 월의 실제 일수 — 클라이언트 1차 검증이고 서버 검증은 기존 그대로).
- 제출 버튼: 미완성 시 회색 비활성 "지도에 올리기", 완성 시 파랑 "{이름} 님을 지도에 올리기". 아래 "다음에 할게요" 텍스트 버튼.
- 제출 로직(API 호출, onAdded → refresh + 선택)은 기존 AddPersonSheet 의 것을 그대로 옮긴다. 기존 폼에만 있고 시안에 없는 요소(예: 윤달 체크 등)가 있으면 **기능은 유지**하고 스타일만 시안 문법으로 입힌다.

### 7. 하지 않는 것

- 배치(layout)·카메라·선 강조 로직·광량 불변식 변경 없음.
- API·DB·공유 접근 규칙 변경 없음.
- 시안의 회색 점선 연결선·1인 mock 데이터는 따르지 않는다.

## 완료 기준

- 지도 페이지 전체가 라이트 테마로 렌더되고, 다크 잔재(네이비 헤더·패널)가 없다.
- 데스크톱에서 우측 400px 패널, 모바일에서 하단 패널(펼침 58vh)이 뜨고 기본 펼침이다.
- 사람 행에 별명·장면명·궁합 단락이 보이고, 3D 노드 탭 ↔ 목록 행이 서로를 가리킨다.
- 추가 모달이 시안 UX(분리 입력·자동 이동·검증·이름 반영 버튼)로 동작하고 실제로 사람이 추가된다.
- `npm test`·`npm run typecheck` 통과 (색·연결선 테스트는 개정판 기준).
- 브라우저 검증: 데스크톱/모바일 스크린샷, 콘솔 에러 없음.
